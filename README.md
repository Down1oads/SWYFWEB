# SWYFWEB

An unofficial browser port of *Scam With Your Friends* (single player, runs entirely in your browser).

- Ported by Down1oads.
- The game, its art, audio and code belong to its original developers. This is a fan port, not affiliated with or endorsed by them. If you are the owner and want it taken down, open an issue and it will be removed.
- To use the AI callers you need your own OpenRouter API key (enter it in the game's Host settings). The key stays in your browser.
- The first load downloads about 400 MB; later visits use the browser cache where available.
